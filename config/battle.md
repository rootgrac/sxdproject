## 3. 占位公式（与 battle-core `engine.ts` 一致）

```
伤害 dmg = max(1, floor(atk × ratio − def × defFactor))   // ratio: 普攻 1 / 绝技 skillRatio
暴击时  dmg = floor(dmg 计算前 raw × critMult)
命中判定: rand < clamp(acc / (acc + eva), 0.05, 0.95)
气势: 普攻命中 actor +25，受到伤害 +15（上限 qiMax）; 未命中不涨气势（占位规则）
行动顺序: 每轮按 spd 降序（同速按阵容顺序）
目标选择: 敌方存活列表首位（M1 布阵接入后按九宫格站位规则）
胜负: 一方全灭即胜; 超过 maxRounds 判平
```
