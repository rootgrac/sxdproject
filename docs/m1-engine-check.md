# M1 引擎内验收向导（BattleGameBoot 可玩循环）

> 状态：待产品负责人执行一次（约 3 分钟）；对应 M1 DoD（开发文档 §4.1 / 附录 D 模板）

## 装配（一次性）

1. 打开 `Main.scene`
2. 层级管理器中选中挂有旧 **BattleDemoBoot** 的节点（原 M0 自动演示）
3. 属性检查器 → 组件列表 → 右键/齿轮 **移除 BattleDemoBoot**（两个组件共存会互相干扰）
4. **添加组件 → BattleGameBoot**（脚本位于 `assets/scripts/modules/game/`）
5. `Ctrl+S` 保存

## 验收流程与检查点

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | ▶ 预览（浏览器） | 主菜单出现：标题 + 3 槽位 + 自动档行 |
| 2 | 点某槽「新档」 | 进入角色面板：Lv1 通脉 / 铜钱 0 / 当前关卡 1_1「山道初行」 |
| 3 | 点「⚔ 挑战」 | 自动战斗播报（普攻/绝技名/治疗/增益）；结束后提示奖励并「已写档」 |
| 4 | 点「下一关」反复挑战 | 铜钱与等级增长；个别关卡可能战败 →「再战」重试 |
| 5 | **刷新页面（=杀进程）→ 重新预览** | 点「继续」→ 角色仍在、进度/铜钱/等级恢复 = **M1 不丢档验收 ✅** |
| 6 | 推完 1_10 | 显示「🏆 第一章已通关」 |
| 7 | （可选）旧档兼容 | 若之前跑过 M0 demo 存档，损坏/版本处理由校验+迁移自动兜底 |

## 已知说明

- 战斗确定性：每关 seed = 1000+chapter×100+node，同关同结果（可回放）
- 存盘点：胜利结算立即写盘（flushNow）+ 每 5 秒脏写节拍 + 切界面时 flush
- 浏览器预览存储 = localStorage；真机（原生）存储驱动将在原生轮接入（drivers.ts 接口已留）
- 数值全部为占位（config/tables 可改，改后跑 `node tools/excel2json/src/run.ts && node tools/sync-config-client.mjs` 再重开编辑器）
